# Text TRPG

브라우저에서 플레이하는 텍스트 기반 1인 던전 탐험 TRPG입니다.
매 탐험마다 새로운 모험가로 시작해, 탐험 중 얻는 스킬과 장비로 빌드를 만들어 던전의 끝을 향해 나아갑니다.

## 플레이

GitHub Pages 주소로 접속하면 바로 플레이할 수 있습니다. 설치나 로그인은 필요 없습니다.

## 데이터와 개인정보

- 이 게임은 서버가 없는 정적 웹 페이지입니다. 어떤 데이터도 수집하거나 전송하지 않습니다.
- 진행 중인 탐험의 자동 저장과 글자 효과 설정은 플레이어의 브라우저(localStorage)에만 남습니다.
- 외부 스크립트·폰트·분석 도구를 사용하지 않습니다.

## 안내

현재는 첫 던전 「속삭이는 숲」의 1구역(숲 초입)까지 플레이할 수 있는 프로토타입입니다.
이 저장소는 배포용이며 자동 생성됩니다. 직접 수정하지 마세요.
